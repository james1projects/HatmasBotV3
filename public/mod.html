MOD CONSOLE

Command availability and per-user cooldowns. Changes apply live; Discord slash commands re-sync within seconds. 0s = no cooldown. Every change is audit-logged. Mods skip cooldowns on Twitch.

Custom text commands. Placeholders: {user} = who ran it, {args} = text after the command. Name: a-z 0-9 _ - only.

Timed messages

Messages rotate inside a lane: one at a time, in the order listed, every N minutes. Lanes run independently; the gap keeps two lanes from posting back to back. "Only while live" holds everything while the stream is offline (timers restart on going live, nothing piles up). "Min chat" on a lane waits until chat has had that many messages since the lane last posted (0 = off). Post now says a message immediately. Every change is audit-logged.
